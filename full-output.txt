===== SINGLY vs DOUBLY LINKED LIST =====

Singly Linked List:
- Each node has 1 pointer (next)
- Can move forward only
- Uses less memory
- Delete from end is O(n)
- Simpler to write

Doubly Linked List:
- Each node has 2 pointers (prev and next)
- Can move forward and backward
- Uses more memory
- Delete from end is O(1) with a tail
- More pointers to manage
